# Upstream research register — 2026-11-19

This is a selective documentation review conducted for the build blueprint, not full source/commit-level audit, not executed integration. URLs are public references. Recheck each on the actual implementation date, record supported installed tool versions, upstream commits/releases, and exact evidence. Older discussion references in `_private/` are historical and not current verification. No name, package, dependency, licensing or provider availability guarantee.

## Phase 0 sources to check additionally (not fully reviewed for this package)

- Claude official [memory](https://code.claude.com/docs/en/memory), [documentation index](https://code.claude.com/docs/llms.txt), agent SDK/session persistence docs, authentication and plugin policies, platform compatibility. Confirm current API/subscription terms; no credential extraction or unsupported auth reuse.
- Codex source [openai/codex](https://github.com/openai/codex), [codex-plugin-cc](https://github.com/openai/codex-plugin-cc), app server/MCP, auth and CLI flags, sandbox OS coverage. Check whether installed version permits expected read-only structured report, context handoff and cancellation.
- [MCP specification](https://modelcontextprotocol.io/), official Go SDK and transport compatibility. Pin protocol and SDK release.
- Claude-Mem [issues #728](https://github.com/thedotmack/claude-mem/issues/728), [#785](https://github.com/thedotmack/claude-mem/issues/785), [#1062](https://github.com/thedotmack/claude-mem/issues/1062), [#2135](https://github.com/thedotmack/claude-mem/issues/2135), [#3195](https://github.com/thedotmack/claude-mem/issues/3195); historical reported startup symptoms, not proof of active defects or user's actual cause. Inspect latest worker implementation and issue status if comparing.
- [Tree-sitter](https://tree-sitter.github.io/tree-sitter/), language grammar licenses, [sqlite-vec](https://github.com/asg017/sqlite-vec), local embedding models and multilingual recall. Benchmark and choose optional parser/model packaging with reviewed licenses.
- [Windows Task Scheduler restart](https://learn.microsoft.com/en-us/windows/win32/taskschd/taskschedulerschema-restartonfailure-settingstype-element), launchd, systemd user units, platform signing/notarization. Verify exact process/session semantics.
- [Go](https://go.dev/), [GoReleaser](https://goreleaser.com/), [Cytoscape.js](https://js.cytoscape.org/), frontend packages and distribution licenses/security advisories.
- [R2 pricing](https://developers.cloudflare.com/r2/pricing/), [AWS S3](https://docs.aws.amazon.com/s3/), [rclone](https://rclone.org/), [Syncthing](https://syncthing.net/), Google Drive/OneDrive API terms and quotas. No fixed cloud prices assumed or cloud accounts connected.
- Optional search providers: Context7, Tavily, Brave Search API, Exa, Firecrawl, GitHub API; inspect official terms, privacy, pricing, limits and version support before adding. Direct HTTP + explicit research records comes first.

Cite official sources and log failed checks. A doc-level result is not runtime verification; a code prototype is not cross-platform proof. No mandatory paid external service assumed.
