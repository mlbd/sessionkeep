## Mutation checks (code temporarily broken, then restored)

| Change | Tests that failed |
|---|---|
| Redaction call removed from the capture path | `TestSecretsNeverReachDisk` |
| Capture level ignored (text kept at every level) | `TestLevelsControlWhatTextIsKept`, `TestAutoModeSpoolsARegistrationRequest` |

During the slice `TestSecretsNeverReachDisk` failed for real: a password passed as `curl -u user:pass` reached the spool. Two redaction rules for command-line credentials were added (`-u/--user user:pass`, `--password/--token/--api-key/... VALUE`) and the test now passes.

## Not run / limits

- The hook has not been registered with Claude Code yet; that is slice 1A-6. Everything here feeds the binary the payloads directly.
- The `systemMessage` reminder is built from the documented hook output field; whether Claude Code 2.1.328 shows it at SessionStart has **not** been observed live.
- Nothing reads the spool yet (slice 1A-5), so captured events are not searchable and auto-add registrations are only requests in the spool.
- Hook deadline is 2 s (ADR-0002 said 60 ms); see DECISIONS D32. The deadline path itself (a stalled disk) is not tested.
- `go test -race` not run (no C compiler). Disk full, power loss and antivirus interference not tested. windows/amd64 only.
- `transcript_path` and `cwd` are stored as given; they contain the user name as part of the path.
