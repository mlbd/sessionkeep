Date: 2026-11-20. Machine: reference Windows 10 Pro 22H2 x64. Real runs against a real listening server and real storage; nothing mocked. No browser was used at any point (owner rule D51) and no Claude Code session was run.

`bash scripts/check.sh` → **CHECK PASSED** (adds `internal/web` and the dashboard tests in `internal/cli`). `node --check` confirms `app.js` parses.

## What exists

`sessionkeep dashboard` prints a one-time sign-in link and serves, on this computer only:

| Page | What it does |
|---|---|
| Overview | what is stored, what is waiting, a button to store waiting events, the current mode for unseen folders |
| Projects | the onboarding screen: add a project (level required, no default), pause/resume, change level, choose manual/ask/auto, manage excluded folders |
| Search | search stored text in one project or all, filter by who said it, exact-string option, full record view, paging |
| Instructions | list with state, record one (preview, then confirm), replace text, archive, history |
| Resume | latest checkpoint, comparison with the code now, instructions, recent exchanges; record a checkpoint |
| Diagnostics | the `doctor` checks and what they do not cover |

## Tests

- `TestDashboardBindsLoopbackOnlyAndSetsSecurityHeaders`: listener is IPv4 loopback; CSP has no `unsafe`, wildcard or remote source; no CORS headers.
- `TestDashboardRefusesEverythingThatIsNotTheSignedInTab`: no cookie → 401 on every API path; guessed cookie → 401; sign-in link reused, wrong or empty → 403 and no cookie; nine request forgeries (no token, wrong token, foreign origin, another local port, `null` origin, cross-site metadata, rebound host name, host without port, form post) all refused, and stored data unchanged afterwards; malformed, unknown-field and oversized bodies → 4xx; unknown endpoints → 404; path tricks never return files from outside the page directory.
- `TestDashboardJourneyThroughTheAPI`: add project (refused without a level), set auto mode (refused without a level), exclude a folder and confirm the hook path honours it, capture through the real hook, store, search, read a record, option-looking query treated as text, record an instruction (preview saves nothing; confirm saves; the next session receives it), replace and archive it, checkpoint, resume, pause and confirm capture stops, diagnostics.
- `TestPagesAreSelfContainedAndInjectionSafe`: exactly three page files; no remote address, `@import` or `url(`; no inline script or style; the script never uses `innerHTML`, `eval`, storage, cookies or dynamic imports.
- `TestAccessibilityBasics`: language, title, one `h1`, main and navigation landmarks, skip link, live status region; every form control has a label; every button has text; column headers marked; no state shown by colour alone; visible focus, dark theme, reduced motion and small-screen rules present.

During the slice the accessibility lint failed twice because of mistakes in the test itself (a pattern that mis-read labels containing brackets, and a crash on a short line); the test was corrected, and one line of the page script was reformatted so its text and state class sit together.
