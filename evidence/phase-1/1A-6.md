## Not run / limits

- Print mode only, one model, two sessions. Interactive mode, `/compact`, resume, tool failures and API errors were not exercised live.
- The owner's other installed plugins were not loaded (`--setting-sources project`), so coexistence with them is still untested.
- The `session_end` event of the last session of the day stays in the spool until the next session or a manual `sessionkeep ingest`.
- An asynchronous drain is killed if the session ends while it runs (documented host behaviour in print mode). That is safe — the drain is idempotent — but not specifically tested live.
- The plugin directory embeds the absolute path of the binary; moving the binary means running `sessionkeep plugin write` again. `doctor` does not check this yet.
- `transcript_path`, `cwd` and tool file paths are stored as given and contain the user name.
- No install into the owner's real Claude Code configuration was done. `go test -race` not run. windows/amd64 only.
