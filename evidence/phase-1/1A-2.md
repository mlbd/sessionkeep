## Not run / limits

- `go test -race`: not run (no C compiler).
- Tests from "every supported previous release": there is no previous release yet.
- Interrupted migration is tested as a failing statement inside the transaction, not as a process kill or power loss mid-migration.
- No concurrency test of this package yet (the Phase 0 spike covered one writer with four readers; the lease holder arrives in 1A-5).
- No repository/query API yet: later slices add typed functions as they need them. Tests exercise the schema with SQL directly.
- Tables for memories, tasks, checkpoints, research, graph, reviews and sync are not created; they belong to later slices and phases.
- `messages` and `transcript_cursors` from the data model are deferred to the slice that reconciles transcripts (ADR-0002 makes that secondary).
- windows/amd64 only.
