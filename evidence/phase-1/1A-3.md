## Not run / limits

- `go test -race`: not run (no C compiler).
- Redaction is pattern matching; `TestKnownGaps` lists three shapes it does not catch (unlabelled secret, unlabelled hex key, secret split across lines). It also over-redacts some harmless assignments.
- Path matching is lexical: no symlink, junction or 8.3 short-name resolution; macOS treated as case-sensitive.
- Auto-add only produces a decision here; the actual registration happens in the ingester (slice 1A-5).
- Administrative commands write the database directly under SQLite locking; the ingest lease arrives in 1A-5.
- No `project remove` command yet. windows/amd64 only.
